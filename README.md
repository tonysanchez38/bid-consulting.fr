# Bid Consulting

Site officiel de [Bid Consulting](https://www.bid-consulting.fr/), spécialisé dans les outils de chiffrage métier, l’analyse de rentabilité et les sites vitrines accessibles aux artisans, TPE et PME.

## Services présentés

- fichiers Excel de chiffrage personnalisés à partir de 89 € HT ;
- analyse visuelle des coûts, du prix de vente, de la marge et de la rentabilité ;
- nomenclature automatique des fournitures selon l’offre choisie ;
- création de site vitrine optimisé pour ordinateur et smartphone.

Le site est statique, sans collecte de données par un formulaire hébergé. Les demandes de contact sont préparées dans la messagerie du visiteur.
