# Bid Consulting

Site officiel de [Bid Consulting](https://www.bid-consulting.fr/) : contre-chiffrage, accompagnement aux marchés publics et outils de chiffrage pour TPE et PME.

## Offres présentées (tarifs HT, octobre 2026)

- Contre-chiffrage : Express 190 € (moins de 30 k€, 72 h ouvrées), Standard 390 € (30 à 150 k€, 5 jours ouvrés), carnet de 5 Standard à 1 750 € ;
- Chiffrage externalisé d’un lot : 590 € (7 jours ouvrés) ;
- Marchés publics : Go / No Go 149 €, Pack Dépôt 790 €, Pack Complet 1 190 €, Pack Groupement 1 490 €, Veille qualifiée 69 € par mois ;
- Outils de chiffrage : modèle standard 49 €, Base 149 €, Rentabilité 249 €, Rentabilité + nomenclature 349 €.

## Pages

- `index.html` : accueil et grille tarifaire ;
- `contre-chiffrage.html` et `marches-publics-tpe.html` : pages d’offre ;
- `outil-chiffrage-artisan.html`, `analyse-rentabilite-chantier.html`, `calcul-prix-vente-artisan.html` : pages de contenu ;
- `site-vitrine-artisan.html` : ancienne offre retirée, redirection vers les offres (non indexée) ;
- `documents/CGV_B2B_Bid_Consulting.pdf` : CGV B2B, version du 14 octobre 2026.

Le site est statique, sans collecte de données par un formulaire hébergé. Les demandes de contact sont préparées dans la messagerie du visiteur.
